### 컬러 매치

> **컬러 매치**는 무작위로 제시되는 '**목표 색상**'을 보고, 제한 시간 내에 **RGB 슬라이더**를 조작하여 **화면의 색상과 가장 유사하게 조합**해 내는 캐주얼 웹 게임입니다.  
> 플레이어의 색채 감각과 순발력을 동시에 테스트하며, 색상을 얼마나 정확하게 맞추었는지, 그리고 얼마나 빨리 완성했는지에 따라 점수와 최종 등급이 결정됩니다.

### 이 앱을 만든 이유

해결하고자 한 문제: 우아한테크코스 8기 크루들이 100명이 넘는 인원이다 보니, 매일 점심시간마다 익숙한 사람들과만 식사하게 되어 새로운 사람들과 친해질 기회가 없는 문제를 해결하고 싶었습니다.

사용 목적: 매일 점심시간, 랜덤으로 짜여진 4~5인의 조원들과 함께 식사하며 서먹했던 크루들과의 친밀감을 높이고 새로운 네트워크를 형성하기 위해 사용합니다.

### 주요 기능

- 닉네임 기반 간편 로그인: 
    - 별도의 회원가입 없이 사전 등록된 크루 닉네임만으로 즉시 이용 가능합니다.

- 실시간 참여 및 메뉴 설정:  
    - 매일 점심시간 전 매칭 참여 여부와 선호하는 식사 장소(구내식당/외부 식당)를 선택할 수 있습니다.

- 랜덤 매칭 알고리즘:
    - 한 팀당 4~5명으로 구성되도록 자동 분배합니다.
    - 특정 식당 선호 인원이 부족한 경우 예외적으로 다른 식당 인원과 함께 매칭시켜줍니다.


- 관리자 전용 대시보드:

    - 전체 크루의 참여 상태를 실시간으로 모니터링하고 조작할 수 있습니다.

    - [매칭 시작] 버튼을 통해 원하는 시점에 즉시 랜덤 배정을 실행합니다.

-  사용자 경험:
    - 매칭 결과 화면에서 어색함을 깨줄 '오늘의 스몰토크 주제'를 제공합니다.
